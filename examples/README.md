# Sample Assessment — Acme Health Pvt Ltd

This directory contains a fully completed sample DPDP Act compliance assessment for a fictional Indian health SaaS company.

## About Acme Health

**Fictional company profile:**
- ~2 million data principals (patients and users)
- Operates a mobile health app and diagnostic booking platform
- Processes health data (sensitive personal data under DPDP)
- ISO 27001 certified
- Not yet designated as a Significant Data Fiduciary but likely candidate
- Privacy Lead: Priya Sharma

## Files

- `acme-health-assessment.json` — Complete assessment answers, importable into the tool

## How to Use the Sample

1. Open DPDP Self-Check at your deployed URL or localhost:3000
2. Click the **Upload** icon in the top bar of the assessment page
3. Select `acme-health-assessment.json`
4. The tool will load all answers and navigate to the results dashboard

## Expected Results

When you load and view this sample assessment, you should see approximately:

- **Composite Score**: ~68-72 (Mature band)
- **Strongest sections**: Security Safeguards, Children's Data, Grievance Redressal
- **Weakest sections**: Significant Data Fiduciary (not yet prepared), Breach Notification (partial)
- **Top gaps**: SDF readiness, breach simulation, notification process testing, nomination feature

This reflects a realistic profile for a 2-3 year old Indian SaaS company with good security fundamentals but privacy-specific compliance still maturing.
